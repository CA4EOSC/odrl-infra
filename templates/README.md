# Templates Folder for Web Interface Customization

This folder contains customizable HTML and text templates for theming the ODRL Infra web interface.

## Available Templates:

- `header.html`: Optional custom HTML inserted into or replacing header elements.
- `footer.html`: Optional custom HTML for the footer.
- `footer.txt`: Optional text override for the footer acknowledgement statement.

## Environment Variables:

- `LOGO_URL`: URL to the logo image (defaults to `https://cdif4eosc.eu/wp-content/uploads/2026/10/logo-2x.png` or `VITE_LOGO_URL`).
